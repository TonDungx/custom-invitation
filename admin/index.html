Kết nối GitHub

Nút Áp dụng lưu nội dung vào config.json trong repo. Cần một token chỉ có quyền ghi vào repo này.

  1. Tạo fine-grained token
  2. Repository access → Only select repositories → chọn repo bên dưới
  3. Permissions → Contents → Read and write
